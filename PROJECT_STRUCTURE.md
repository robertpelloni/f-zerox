## Directory Layout
- **root**: Contains build scripts (`Makefile`), configuration (`.yaml`), and documentation.
- **src/**: Decompiled C source code (`.c`) and top-level assembly (`.s`).
    - Files are named `game_ADDRESS.c` pending proper renaming.
- **include/**: C header files (`.h`).
    - `structs.h`: Game structures (many auto-generated).
    - `variables.h`: Global variable declarations.
    - `functions.h`: Function prototypes.
- **asm/**: Disassembled assembly code (generated by `make extract`).
    - `nonmatchings/`: ASM that hasn't been decompiled/matched yet.
- **tools/**: Build tools and submodules.

## Build System
- **make extract**: Splits the `baserom.us.z64` into parts defined in `f-zerox.us.yaml`.
- **make**: Compiles C files, assembles ASM, and links the final ROM.
